# Литр До Дома: Симулятор Очереди

Пиксельная городская аркада про топливный кризис в вымышленном Нефтеграде.
Ищите работающие АЗС, занимайте очередь, следите за баком и прокачивайте машину.

- Движок: Flutter (Dart 3), графика рисуется кодом
- Платформа: Android (APK/AAB для RuStore)
- Режимы: свободная поездка, выживание, кампания на 7 дней
- Без интернета, без рекламы, без встроенных покупок

Сборка: `pwsh -File build_apk.ps1 -Icons -Sounds`

## Материалы для магазина

- `store/icon_512.png` — иконка 512x512 для RuStore
- `store/logo.png` — логотип для карточки
- `store/rustore_description.txt` — краткое и полное описание
